## leetcode 32 Longest Valid Parentheses

你的直觉非常敏锐。**单调栈**（或者说普通的栈）在处理“括号是否合法”时是完美的，但在处理“**最长连续合法长度**”时，确实会遇到你说的“信息断层”问题。

普通的栈只能告诉你当前这一对是否匹配，但它很难自动把“断断续续”的合法片段连起来。

### 🧠 1. 核心困惑：为什么会“判断完失败就直接结束”？

比如 `() (())`，中间那个空格（或者多余的右括号）会把两段合法的括号切断。
你的思路缺陷在于：**栈里只存了字符，没有存“位置”。** 

### 🚀 2. 整体思维：栈里存“下标”

要解决“最长”和“连续”的问题，秘诀是：**栈里不存字符 '('，而是存它的索引 `i`。**

我们将栈定义为：**“最后一个未匹配的右括号的下标”**。它就像一个“锚点”，标记了当前合法序列的“起点前一个位置”。

#### 算法逻辑：
1. **初始化**：先往栈里压入一个 `-1`（作为虚拟锚点）。
2. **遇到左括号 `(`**：把它的下标 `i` 压入栈。
3. **遇到右括号 `)`**：
   * **先弹出**栈顶元素（代表匹配了当前这个右括号）。
   * **检查栈是否为空**：
     * **如果栈空了**：说明当前的右括号是多余的，没有左括号能匹配它。它成了**新的锚点**，我们把当前下标 `i` 压入栈。
     * **如果栈不空**：说明匹配成功！当前的合法长度 = `当前下标 i - 弹出后的新栈顶下标`。

---

### 💻 3. 代码实现

```cpp
int longestValidParentheses(string s) {
    stack<int> st;
    st.push(-1); // 初始锚点
    int maxLen = 0;

    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '(') {
            st.push(i); // 存下标
        } else {
            st.pop(); // 尝试匹配
            if (st.empty()) {
                // 栈空了，说明这个右括号是多余的，作为新的起跳锚点
                st.push(i);
            } else {
                // 栈不空，当前长度 = i - 栈顶元素（即上一个没匹配的下标）
                maxLen = max(maxLen, i - st.top());
            }
        }
    }
    return maxLen;
}
```

---

### 🛡️ 4. 为什么这个思路能“整体来看”？

让我们模拟 `()(())`：
1. `i=0, '('`: 栈 `[-1, 0]`
2. `i=1, ')'`: 弹出 `0`，栈 `[-1]`。长度 `1 - (-1) = 2`。`maxLen = 2`。
3. `i=2, '('`: 栈 `[-1, 2]`
4. `i=3, '('`: 栈 `[-1, 2, 3]`
5. `i=4, ')'`: 弹出 `3`，栈 `[-1, 2]`。长度 `4 - 2 = 2`。
6. `i=5, ')'`: 弹出 `2`，栈 `[-1]`。长度 `5 - (-1) = 6`。`maxLen = 6`。

**你看，通过存下标，栈自动帮你把中间匹配掉的部分“跨”过去了！**

---

### 💡 5. 另一种“降维打击”：双向计数法（不用栈）

如果你在面试中忘了栈的技巧，还有一个**空间复杂度 $O(1)$** 的神技：

1. **从左往右扫**：记录 `left` 和 `right` 数量。
   * 如果 `left == right`，更新 `maxLen`。
   * 如果 `right > left`，说明非法，计数器归零。
2. **从右往左扫**（解决 `((()` 这种左括号过多的情况）：
   * 如果 `left == right`，更新 `maxLen`。
   * 如果 `left > right`，计数器归零。

**这种“双向奔赴”的做法非常优雅，完全不需要额外的空间！**
