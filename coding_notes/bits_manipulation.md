## leetcode 191 Number of 1 bits

你好！很高兴看到你开始接触**位运算（Bit Manipulation）**。这是算法竞赛中的基本功，也是最能体现代码“优雅”和“高效”的地方。

第 191 题（位 1 的个数）在竞赛界是一个非常经典的问题。你提到的“转换成二进制再统计”逻辑上是完全正确的，但在计算机底层，数字本身就是以二进制存储的，所以我们不需要显式转换，直接在位上操作即可。

---

### 🧠 题目背后的算法模型

统计二进制中 1 的个数，专业术语叫 **汉明重量（Hamming Weight）**。针对你的困惑，我有两种从“普通”到“天才”的优化思路推荐给你：

#### 1. 逐位检查法（基础思路）

这是最直观的方法。就像你数一排士兵里有多少人穿红衣服一样，一个一个看。

* **原理**：利用位运算 `n & 1`。如果结果是 1，说明最低位是 1；然后将 `n` 右移一位（`n >>= 1`），继续检查下一位。
* **效率**：对于 32 位整数，无论 1 有多少个，都要循环 32 次。
* **复杂度**：O(k)，其中 k 是整数的位数（如 32）

#### 2. Brian Kernighan 算法（优化思路 —— 强烈推荐）

这是竞赛选手常用的技巧，它能**跳过所有的 0**，只数 1。

* **核心公式**：`n = n & (n - 1)`
* **原理**：
* 当你执行 `n - 1` 时，`n` 二进制中最右边的那个 `1` 会变成 `0`，而它右边的所有 `0` 会变成 `1`。
* 当你再执行 `n & (n - 1)` 时，这个操作会精准地**把 `n` 中最右边的那个 `1` 给消掉**，其他位保持不变。


* **效率**：数字中有几个 1，循环就执行几次。如果只有 1 个 1，它只跑一次循环。
* **复杂度**：O(m)，其中 m 是 1 的个数。

---

### 💻 C++ 代码实现

这里我给出最推荐的 **Brian Kernighan 算法** 写法，代码简洁且运行效率极高：

```cpp
class Solution {
public:
    int hammingWeight(uint32_t n) {
        int count = 0;
        while (n != 0) {
            // 核心技巧：每次操作都会消除 n 二进制表示中最右边的一个 1
            n &= (n - 1);
            count++;
        }
        return count;
    }
};

```

---

### 🛡️ 教练评估与建议

* **你的初步想法**：将十进制转二进制。
* **缺陷**：在 C++ 中，如果你手动去求余（`n % 2`）和除法（`n / 2`）来模拟进制转换，虽然结果正确，但会涉及到较多的 CPU 指令周期。
* **优化点**：直接使用位运算符（`&`, `>>`, `<<`）速度极快，因为它们是 CPU 原生支持的指令。

> **ACM 小贴士**：在 C++ 中，其实有一个内置函数 `__builtin_popcount(n)` 可以直接返回 1 的个数，它是通过硬件指令实现的，速度最快。但在面试或初学阶段，掌握 `n & (n - 1)` 的原理至关重要。

### 🚀 还能更快吗？—— 分治法（Divide and Conquer）

虽然  已经很快了，但在一些极致性能要求的场景（或者面试官想考你深度时），我们可以用**分治思想**。

既然要颠倒 32 位，我们可以：

1. 交换前 16 位和后 16 位；
2. 在这 16 位内部，交换前 8 位和后 8 位；
3. 在这 8 位内部，交换前 4 位和后 4 位；
4. 依此类推，直到交换相邻的 1 位。

这种方法利用了特定的**位掩码（Mask）**，可以实现真正的“并行计算”感官，代码执行次数从 32 次循环缩减到了 5 步位运算。

---

### 💻 进阶 C++ 写法：分治位移

这种写法在处理大规模数据时非常有优势，也被称为“位杂凑（Bit Twiddling Hacks）”：

```cpp
class Solution {
public:
    uint32_t reverseBits(uint32_t n) {
        // 1. 交换相邻的 16 位
        n = (n >> 16) | (n << 16);
        // 2. 交换相邻的 8 位
        n = ((n & 0xff00ff00) >> 8) | ((n & 0x00ff00ff) << 8);
        // 3. 交换相邻的 4 位
        n = ((n & 0xf0f0f0f0) >> 4) | ((n & 0x0f0f0f0f) << 4);
        // 4. 交换相邻的 2 位
        n = ((n & 0xcccccccc) >> 2) | ((n & 0x33333333) << 2);
        // 5. 交换相邻的 1 位
        n = ((n & 0xaaaaaaaa) >> 1) | ((n & 0x55555555) << 1);
        return n;
    }
};

```

#### 为什么这更强？

* **无循环**：去掉了循环开销。
* **掩码原理**：比如 `0x55555555` 对应的二进制是 `01010101...`，通过它我们可以一次性提取出所有偶数位或奇数位进行交换。

---

### 🛡️ 教练评估

* **你的解法**：优秀的  线性扫描。优点是通俗易懂，不容易出错。
* **分治解法**： 即 5 步操作。优点是极致高效，充分利用了 CPU 对位掩码的处理能力。

---

### 🚀 进阶：动态规划 + 位运算 (DP on Bits)

在 ACM 竞赛中，这种“利用已知求未知”的方法叫**动态规划（Dynamic Programming）**。针对这道题，我们有两种极其优雅的  做法：

#### 方法 A：利用 `i & (i - 1)` (最推荐，最符合你现在的直觉)

记得 `i & (i - 1)` 的作用吗？它消掉了 `i` 最右边的那个 `1`。

* **递推公式**：`res[i] = res[i & (i - 1)] + 1;`
* **原理**：`i & (i - 1)` 得到的数字一定比 `i` 小，所以它的 1 的个数我们已经在之前算过了。我们只需要在那个基础上加 1（补回那个被消掉的 1）即可。

#### 方法 B：利用奇偶性（左移/右移）

* **如果 `i` 是偶数**：它的二进制末尾是 `0`，所以它的 1 的个数和 `i >> 1`（即 `i/2`）是一模一样的。
* **如果 `i` 是奇数**：它的二进制末尾是 `1`，所以它的 1 的个数等于 `i >> 1` 的结果加 1。
* **递推公式**：`res[i] = res[i >> 1] + (i & 1);`

---

### 💻 优化后的 C++ 代码 (方法 A)

这种写法省去了内部的 `while` 循环，时间复杂度直接降到 。

```cpp
class Solution {
public:
    vector<int> countBits(int n) {
        vector<int> res(n + 1, 0);
        // 从 1 开始，因为 res[0] 默认就是 0
        for (int i = 1; i <= n; ++i) {
            // i & (i - 1) 得到的数比 i 小，且其 1 的个数已知
            res[i] = res[i & (i - 1)] + 1;
        }
        return res;
    }
};

```

### 🧠 题目背后的算法：异或（XOR）的魔法

面对这道题，我们要祭出位运算中最神奇的运算符：**异或 `^**`。

在二进制运算中，异或的规则是“相同为 0，不同为 1”。但作为竞赛教练，我要求你记住它在宏观上的三个**神级性质**：

1. **归零律**： （任何数和自己异或，结果为 0）
2. **恒等律**： （任何数和 0 异或，结果不变）
3. **交换律与结合律**：

### 💡 教练思路评估

如果你把数组中所有的数字全部“异或”在一起：

* 成对出现的数字，根据**交换律**，它们总会相遇。
* 根据**归零律**，这些成对的数字异或后全部变成 。
* 最后剩下的，就是  与那个“只出现一次的数字”进行异或。
* 根据**恒等律**，结果就是我们要找那个数字！

---

### 💻 C++ 代码实现

由于异或运算不占额外空间，且只需要遍历一次数组，它完美符合  时间和  空间的要求。

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int res = 0;
        for (int x : nums) {
            // 将数组中所有数字依次进行异或
            res ^= x;
        }
        return res;
    }
};

```

## leetcode 268

好教练最喜欢的时刻，就是看到学生能举一反三，并开始在大胆尝试中遇到“挫折”——因为这是查漏补缺的最佳时机！

---

### 🔍 错误代码诊断

我们来复盘一下你的代码逻辑：

```cpp
for (int num : nums) {
    res = n ^ num; // 陷阱1：赋值操作符覆盖了之前的结果
    n += 1;        // 陷阱2：变量 n 的起始值和变化规律不对
}

```

1. **赋值 vs 累计（关键点）**：
你用了 `res = n ^ num;`，这会导致 `res` 每次都被**重新赋值**，只记住了最后一次的结果。我们需要的是**累加异或**，应该用 `res ^= (n ^ num);` 或者分两步走。
2. **数值范围不对**：
如果数组长度是 ，数字范围是 。你的循环只跑了  次（数组的大小），导致最后一个数字（那个 ）可能没被参与运算。

---

### 💡 教练的纠正方案

我们要保证：**[0, n] 里的每一个数** 和 **数组里的每一个数** 都参与异或。

#### 方案一：同步抵消法

我们可以利用索引 `i` 和数组里的值 `nums[i]` 一起异或。

```cpp
int missingNumber(vector<int>& nums) {
    int res = nums.size(); // 先把 n 本身存进去
    for (int i = 0; i < nums.size(); i++) {
        // 让索引 i 和 数组里的值 nums[i] 互相抵消
        res ^= i ^ nums[i]; 
    }
    return res;
}

```

#### 为什么这样能行？

假设 `nums = [3, 0, 1]`，`n = 3`：

* 初始 `res = 3`
* 第一轮：`res = 3 ^ (0 ^ 3)` （索引 0 和 数组值 3）
* 第二轮：`res = 3 ^ 0 ^ 3 ^ (1 ^ 0)` （索引 1 和 数组值 0）
* 第三轮：`res = 3 ^ 0 ^ 3 ^ 1 ^ 0 ^ (2 ^ 1)` （索引 2 和 数组值 1）
* **整理一下**：所有的数其实是 `(0^1^2^3) ^ (3^0^1)`。
* 根据“归零律”，重复的 `0, 1, 3` 全部变 0，最后只剩下 `2`。

---

### 🛠️ 另一种“数学流”解法（ACM 常用）

除了位运算，这道题在竞赛中还有一个更快的 ** 空间**解法：**等差数列求和**。

1. 算出  的理论总和：
2. 算出数组 `nums` 的实际总和。
3. **缺失值 = 理论总和 - 实际总和**。

```cpp
int missingNumber(vector<int>& nums) {
    int n = nums.size();
    int expectedSum = n * (n + 1) / 2;
    int actualSum = 0;
    for (int x : nums) actualSum += x;
    return expectedSum - actualSum;
}

```
